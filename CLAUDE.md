# EirePg
Older project created with CodeSandbox (React, `src/` and `public/`). This repository is public: never commit anything private.

## How to work (Claude Code)
- Make every change on a new branch named `claude/<short-topic>` and open a pull request. Never push directly to `main`, never force-push.
- Merge only when Derek says "merge".
- Keep secrets, passwords, API keys and `.env` files out of Git.
- Stay within the requested scope, batch related changes, and run focused checks for what changed.
- Finish with a short plain-English summary: what changed, what was checked, anything left to do.
